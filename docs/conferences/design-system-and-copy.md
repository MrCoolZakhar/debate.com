## 8. Design system and copy

- **How a run is tested (owner decision, 16 Oct 2026: "check it landed, it works, then I go in to test regardless"). Every session follows this unless a prompt explicitly says otherwise.**
  - After building, run `npm run build` ONCE and `npx eslint` on the files touched. That is the whole test.
  - Then read your own diff once: every PART of the prompt is wired (each quoted string exists, each new prop is passed, each new hook is above the early returns, nothing in WHAT MUST NOT CHANGE was touched).
  - Do NOT open the browser, run Playwright, take screenshots, stub RPCs, create test data or retry checks. The owner runs every test himself in a test-run artifact.
  - The final report is short: what landed per PART (one line each), any deviation and why, every file changed, and anything that could not be wired. No "Checked" section.
- **No empty bands (owner decision, 16 Oct 2026: "it's annoying to constantly remind you this space is ugly"). Every session follows this.**
  - A page or tab fills its content width at 1440 and 1920; never leave a wide empty area beside the content (for example a max-width card on the left with cream space on the right).
  - When content is narrow, lay it out in columns or a grid, or widen the cards; never cap a whole page at a reading width unless it is a page of long text.
  - When you build or change a layout, read your diff for fixed max-widths on page-level containers and remove the ones that leave empty space.
- **A pop-up never opens another pop-up on top of itself (owner decision, 16 Oct 2026). Only the owner or Peter may ask for an exception.**
  - A second step (add, edit, upload, view submissions) REPLACES the content of the same pop-up, with a back button to where it came from.
  - Small menus and confirms are not pop-ups, but they must fit inside the pop-up that holds them: a menu stays within the pop-up's edges (opening upward or leftward when there is no room) and scrolls itself; a confirm is asked in place (a row or a line in the pop-up), never as a modal over it.
