- Checked on a 15 s interval while eligible, and again on `visibilitychange` (a background tab is never interrupted; it is checked the moment it is shown); state changes once (open). No committee state, no writes. If eligibility drops while open (caucus ends, suspension, gavel moves) it disappears for good.
- `GrowDialog` (z-50, focus trap, Escape, backdrop, focus return, reduced-motion fade), growing from the unmoderated countdown. Forest panel, no icon tiles, no row animation. No em dashes in the copy.
