## COMPONENT: Floor emblem (17 Sep 2026)
- `src/components/FloorEmblemBackdrop.tsx`, mounted once as the first child of the chair page's floor `<main>`, which is `relative isolate` for it. The Gavelling mark (gavel over the laurel wreath) drawn very large and very faint as a soft neumorphic EMBOSS in the exact outline of the logo: `/gavelling-mark.png`'s alpha is a CSS mask (never drawn as a picture), a warm-white highlight rim (mark minus itself shifted down-right) and a forest-tinted shadow rim (shifted mark minus mark, `mask-composite: subtract` / `-webkit-mask-composite: source-out`), both lightly blurred, over a barely lighter face. **Strength (17 Sep 2026, later the same day, owner: "make it just a slimmer, less subtle so it's more visible, but just the slightest bit")**: x1.4 on the barely-visible values, i.e. face `rgba(255,252,244,0.049)`, shadow rim forest at 0.034, highlight rim at 0.238 (from 0.035 / 0.024 / 0.17). Noticed once, then forgotten. Do not raise it further without being asked.
- **Centred on the element with class `floor-emblem-anchor`** inside `<main>`: the GSL floor flag, the moderated caucus / Tour de Table floor flag, the Room Order number disc, and the unmoderated / Consultation countdown. No anchor (empty GSL, caucus with nobody on its floor, voting card) = the centre of the floor. Keep that class on whatever you draw as the floor speaker.
- Size = min(94% of the floor height, 90% of its width, 920px), min 240px; emboss depth scales with it.
- z-index -1 inside `<main>`'s stacking context: above the page ground, below every piece of floor content, so text contrast is untouched. `pointer-events: none`, `aria-hidden`. Static, no animation.
- **No React state and nothing per second (RULES 3 and 4).** Position and size are written to the node, re-measured only on a ResizeObserver (floor, anchor) or MutationObserver (`childList` only, so a clock tick, which rewrites a text node, never triggers it) callback, coalesced into one rAF (with a 120 ms timer behind it, since rAF and ResizeObserver pause in a hidden page; `visibilitychange` re-places too) and skipped when unchanged. Rects are divided by the FitToScreen scale.
- Side effect of `isolate` on `<main>`: floor content with its own z-index (the CoW timer overlay, a dragged strip flag) now stacks inside `<main>`, so the page grain overlay (z-1, 0.18 multiply) lies over it too. Portaled layers are unaffected.
